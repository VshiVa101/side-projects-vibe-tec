# Pip-Folio

Portfolio UX/UI in stile Pip-Boy con approccio fake-3D:
- Layer 0: video sfondo (`public/assets/video/bg-loop.mp4`)
- Layer 1: overlay braccio (`public/assets/images/pipboy-arm.png`)
- Layer 2: UI Pip-Boy in React/Next.js

## Setup locale

```bash
npm install
npm run dev
```

## Dove mettere gli asset

- Video: `public/assets/video/bg-loop.mp4`
- PNG braccio: `public/assets/images/pipboy-arm.png`
- Audio radio (opzionale): `public/assets/audio/`

## Deploy gratuito (Vercel)

1. Crea repo GitHub e fai push del progetto.
2. Vai su https://vercel.com/new
3. Importa il repo.
4. Framework auto-rilevato: Next.js.
5. Deploy.

Otterrai un dominio gratuito `*.vercel.app`.
